# Welcome to my blog

Hi — welcome! This space is where I document my learning journey in cybersecurity, share tutorials, write small tools and recon notes, and explain concepts in a practical, hands‑on way.

Whether you're learning to recon, exploring web security, or just curious about tooling and automation, you'll find clear writeups, examples, and reproducible steps you can try locally.

## What this blog is about

I write about:

- Practical recon techniques (DNS, endpoints, automated checks)
- Tooling and scripts I build or improve (parsers, scanners, wrappers)
- Walkthroughs and how‑tos (Hugo tips, CI/CD snippets, deployment notes)
- Short writeups on security concepts and recent things I study
- Postable, copy‑pasteable code examples and Markdown documentation

I aim to keep posts focused: reproducible commands, sample outputs, and a short explanation of *why* the technique matters.

## Who I am

I'm a cybersecurity engineer learning by building and teaching. I enjoy:

- building automation and recon pipelines
